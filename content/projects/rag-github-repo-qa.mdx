## Overview

A full-stack Retrieval-Augmented Generation (RAG) tool built to help developers comprehend unfamiliar codebases faster. By pasting any public GitHub repository link, users can ask natural-language architectural and algorithmic questions and receive answers grounded directly in the repository's source code snippets.

---

## Problem

Understanding large, unfamiliar codebases during onboarding or open-source research is traditionally time-consuming:
- Keyword searches (grep, basic GitHub search) fail on high-level conceptual questions (e.g., *"Where is user session persistence handled?"*).
- General LLMs without codebase retrieval hallucinate function signatures, assume non-existent modules, or rely on outdated knowledge.
- Developers need a focused tool that ingests specific repository trees and provides verifiable context citations.

---

## Approach

1. **Repository Ingestion & Preprocessing**:
   - Clones target public GitHub repositories and filters files by relevant programming languages, excluding build artifacts (`node_modules`, `.git`, binaries).
   - Chunks source code while maintaining logical boundaries and metadata (relative file paths, line numbers, function blocks).
2. **Dense Vector Embeddings & ChromaDB Storage**:
   - Generates dense vector representations for each code snippet using `sentence-transformers`.
   - Stores and indexes embeddings in ChromaDB to enable low-latency semantic cosine similarity search for top-K code chunks.
3. **Anthropic API Integration**:
   - Connects retrieved source code snippets into prompt templates sent to the Anthropic API (Claude).
   - The model synthesizes clean, grounded responses referencing the exact retrieved files and code logic.
4. **Interactive Streamlit Interface**:
   - Simple, responsive web UI built with Streamlit allowing developers to paste repository URLs, track ingestion progress, and interactively converse with the codebase.

## Architecture & Tech Stack

```
[ GitHub Repo URL ] ──► Repo Cloner & Source Filter ──► Semantic Code Chunker
                                                              │
                                                              ▼
[ User Question ] ──► Sentence-Transformers ──► ChromaDB Vector Store (Top-K)
                                                              │
                                                              ▼
[ Grounded Answer ] ◄── Streamlit Web UI ◄── Anthropic API (Claude Context Injection)
```

### Core Technologies
- **Frontend**: Streamlit — rapid interactive UI for repository loading and chat streaming.
- **Backend & Embeddings**: Python 3, `sentence-transformers` for dense semantic vector representations.
- **Vector Database**: ChromaDB — persistent local vector database for semantic top-K retrieval.
- **Language Model**: Anthropic API (Claude) — context-grounded reasoning and code generation.

---

## Result

- Built and deployed a full-stack RAG web application capable of ingesting public repositories on demand.
- Successfully parses, chunks, and indexes source code into ChromaDB for semantic retrieval.
- Integrated Anthropic API to generate grounded, context-aware answers from retrieved code snippets, significantly cutting manual repository exploration time for unfamiliar codebases.
