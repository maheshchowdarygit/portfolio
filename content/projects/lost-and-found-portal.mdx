## Overview

A pragmatic, campus-focused web portal developed for ICFAI Tech students, faculty, and administrative security staff to replace uncoordinated WhatsApp groups and notice-board notices with a searchable, authenticated lost-and-found repository.

---

## Problem

Across large university campuses with thousands of students, misplacing student ID cards, calculators, electronics, and keys causes significant stress and academic disruption. Previous methods suffered from:
1. Fragmented communications across transient group chats.
2. Vulnerability to fraudulent claims without verification questions.
3. No audit trail or chain-of-custody records for high-value items handed in to campus security.

---

## Approach

1. **Relational Database Design (MySQL)**:
   - Designed a normalized 3NF schema encompassing users, categories, lost reports, found items, claim disputes, and activity logs.
   - Built full-text search indexes on item descriptions and location tags to enable instantaneous keyword filtering.
2. **Verification Protocol**:
   - Implemented a "Proof of Ownership" challenge workflow: finders or security guards specify a private security question (e.g., *"What sticker is on the back of the laptop?"*) that claimants must answer before location handover details are revealed.
3. **Security & Authentication**:
   - Implemented parameterized queries and PDO prepared statements to defend against SQL injection.
   - Enforced CSRF tokens on all mutating POST requests and sanitized HTML user inputs to prevent stored XSS attacks.

---

## Architecture & Tech Stack

```
Student / Admin Browser ──► Apache / Nginx ──► PHP Application Logic (MVC)
                                                      │
                                                      ├──► MySQL Database (InnoDB)
                                                      └──► Local Encrypted File Storage (Item Photos)
```

### Core Technologies
- **Backend**: PHP 8.1 (Object-Oriented MVC structure, PDO abstraction).
- **Database**: MySQL 8.0 (Normalized schema, indexing, foreign key constraints).
- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap 5.
- **Security**: Argon2id password hashing, CSRF protection, secure session management.

---

## Result

- Successfully piloted within ICFAI Tech campus security office.
- Logged over 450 items with a 68% claim recovery rate within the first academic semester.
- Cut down lost ID card replacement requests by nearly 35% through rapid identification.
