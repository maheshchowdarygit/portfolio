## Overview

A practical campus web portal designed to help students and administrative staff report, track, and recover misplaced items across campus through an organized database and real-time query interface.

---

## Problem

On college campuses, lost student ID cards, notebooks, and electronics are often shared haphazardly across temporary group chats or bulletin boards. This causes:
- Inefficient searchability without structured categorization or status tracking.
- Difficulties in validating whether a claimant is the legitimate owner.
- Lack of centralized records for resolved claims.

---

## Approach

1. **Relational Database Design (MySQL)**:
   - Designed and built normalized relational schema and backend queries powering item posting, status tracking (lost, found, claimed), categories, and user accounts.
   - Indexed frequently queried fields (category, timestamp, status, location tags) to speed up search lookups.
2. **Search & Filter Query Logic**:
   - Wrote optimized SQL joins and multi-condition filtered queries to support real-time search across active listings.
   - Allowed filtering by item type, date range, and location found.
3. **Claim Workflows & Authentication**:
   - Implemented user registration and session-based authentication to manage listings.
   - Built a claim workflow enabling users to submit ownership details and contact information to securely arrange handoffs.

---

## Architecture & Tech Stack

```
[ Student / User ] ──► Web Browser ──► PHP Application Backend
                                              │
                                              ├──► User Session Auth
                                              ├──► Query & Filter Engine
                                              └──► MySQL Database (InnoDB Schema & Joins)
```

### Core Technologies
- **Backend**: PHP — server-side rendering, request routing, and business logic.
- **Database**: MySQL — relational schema design, foreign key integrity, and indexed SQL queries.
- **Frontend**: HTML5, CSS3, JavaScript — responsive interface for listing items and browsing claims.
